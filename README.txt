ROULETTE PULSE — ANDROID
Projeto pronto para abrir no Android Studio.

GERAR APK:
1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. APK: app/build/outputs/apk/debug/app-debug.apk

Uso: registre cada resultado 0–36 em um toque. O app mantém o histórico local e recalcula dúzias, colunas, transições e 3 bases de vizinhos.
Os sinais são estatísticos e não garantem acerto ou lucro.
